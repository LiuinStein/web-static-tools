# 编码规范

## 下拉框

本规范适用于新增、修改和重构下拉选择控件，包括页面表单、筛选栏、可编辑表格和挂载到页面外的弹窗。交易日记的下拉框是箭头与文字留白的视觉基准。

### 统一入口

原生单选下拉框使用 `src/styles/select.css`，由 `src/global.css` 在应用入口统一引入。新页面直接使用语义化的 `<select>`、`<option>` 和关联标签，无需额外导入样式、添加专用类名或复制 SVG。

共享规则自动覆盖普通单选、`size="0"` 和 `size="1"` 的下拉框；`multiple` 多选和 `size` 大于 1 的列表框不绘制该下箭头。

### 箭头与文字留白

| 项目 | 统一规则 |
| --- | --- |
| 箭头背景尺寸 | 12px × 12px，垂直居中 |
| 箭头背景距右侧 | 默认 8px，不得贴边 |
| 文字右侧留白 | `calc(var(--select-arrow-inset, 8px) + 24px)`，默认 32px |
| 长选项 | 保留箭头区域，文字可省略，展开菜单可查看完整选项 |
| 响应式 | 桌面、平板、手机均使用同一套箭头与留白规则 |

确有布局需要时，只在容器上设置 `--select-arrow-inset`。该值不得小于 8px，文字留白随变量同步计算。工资页现有 16px 是保留的差异，不要把该差异复制到其他页面。

```css
/* 仅在确有需要的容器上调整距离。 */
.example-page {
  --select-arrow-inset: 16px;
}
```

### 禁止业务样式覆盖箭头

页面和业务组件可以定义下拉框的宽高、字体、边框、圆角和背景颜色，但必须保留共享规则管理的箭头与文字区域：

- 不得设置 `appearance: auto` 或 `-webkit-appearance: auto`，恢复浏览器默认贴边箭头。
- 不得覆盖 `background-image`、`background-position`、`background-size`、`background-repeat`，或另画一套原生下拉箭头。
- 不得通过 `padding-right`、`padding-inline-end` 或 `padding` 简写覆盖共享的右侧文字留白。表单公共样式即使同时作用于输入框和下拉框，也必须检查最终计算值。
- 修改下拉框底色使用 `background-color`，不要用 `background` 简写清除箭头。悬停、禁用、只读和错误状态同样适用。
- 不得通过负外边距、`right: 0`、逐页补丁或增加 `!important` 解决贴边问题；应检查并修正共享样式与业务覆盖规则。
- 不得依赖页面样式的加载顺序。懒加载其他页面、返回原页面后，箭头与留白必须保持一致。

此前股票、债券的共用样式曾通过 `appearance: auto` 和 `background-image: none` 覆盖共享规则，导致箭头再次贴边。后续重构公共表单时不得重新引入这类覆盖。

### 组件库与自定义下拉框

Fusion `Select`、`Select.AutoComplete` 和自定义选择器不一定使用原生 `<select>`，不能仅凭全局原生样式推断它们已符合规范。

- 优先复用组件库或项目已有的共享实现，保持文字与箭头分离，箭头不可遮挡文字或顶住边框。
- 确需新增适配时，提取为可复用组件或共享样式，使用统一的间距变量；不得在各业务页复制箭头实现。
- 已有期货汇率来源选择器使用独立箭头样式；修改它时必须单独核对箭头距离、图标与文字的占位以及菜单边界。
- 自动补全输入框按其交互设计保留是否显示箭头的行为，不要为了统一外观强制添加箭头或破坏输入能力。
- 菜单展开后应位于可视区域内，选项可读、可选；保留键盘操作、标签、焦点和禁用状态。

### 修改后的检查

凡修改下拉框、公共表单样式或影响其容器的布局，完成以下检查再报告完成：

1. 检查 1440px 桌面、768px 平板、390px 和 320px 手机宽度；同时查看控件收起和菜单展开状态。
2. 检查箭头右侧间距、文字右侧留白、长选项、禁用状态及选择切换，确认没有贴边、重叠、裁切或菜单越界。
3. 检查页面、筛选栏、表格和弹窗中的下拉框，尤其是通过 portal 挂载到页面外的弹层。
4. 涉及全局样式时，回归股票、债券、交易日记、工资、月度复盘，以及期货汇率与货币工具预设选择器；打开有数据的页面和相关弹窗，不能只检查空页面。
5. 通过应用内导航切换页面并返回，检查懒加载样式的相互影响；必要时检查不同加载顺序。
6. 结合浏览器实际显示与计算样式验证，不能只凭源码中的 `padding` 数值判断已修复。无法进入的连接状态应说明验证范围。

具体工具页布局约定见 [工具页共享 CSS 模板](../src/components/ToolPage/README.md)。
