# 债券到期收益工具

股票、债券工具共用 `../CalculatorLayout/style.css`，保持字号、配色、顶部间距、主次结果、分割线、输入区与明细表一致。

费率核对于 2026-11-04，来源链接随券商显示：

- 富途香港：主权债（含美债）、企业 / 金融 / 城投债、困境债；USD / HKD / CNH 对应不同平台费上下限。
- uSMART 香港个人账户：美元美国国债及企业债。前者当前无托管费；后者按月末持仓市值计收，最低 10 USD / 月。按本工具作为唯一一笔持仓估算，最低收费不能在多笔持仓中重复套用。赎回、公司行动等适用收费需填写「其他费用」。
- Schwab International：美国国债及列示的其他二级市场债券，USD。普通美国国债线上免费；其他二级市场按每 1,000 面值收取 1 USD，最低 10、最高 250。报价须未包含本页另算的交易费；报价中已包含的费用不能再算一次。
- ZA Bank：没有找到普通个人账户直投债券的公开交易入口及费率，暂不列入；未将债券基金或南向通一般合格产品说明视为可交易、可计费的普通债券服务。

计算为持有到期单利估算，**非 YTM**。按实际持有天数 / 365 估算净利息，按面值偿还本金。未逐期排息，未独立计算交割应计利息，也未预测价格、汇率、融资和税费。托管计费市值近似为买入成交金额。

uSMART 企业债按 `[交割日, 到期日)` 区间内的持仓月末数估算；每个月先按金额下限与两位小数计费，再加总。到期日视为已兑付。实际账单的月末持仓、账户整体最低费及额外费用可能不同。

`npm run test:bond` 覆盖券商支持组合、费率上下限、月托管费、STRIPS 区分、日期与空值，以及完整现金流对账。
