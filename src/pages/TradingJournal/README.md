# 交易日记

页面：`/#/trading-journal`。所有资金字段使用用户输入的原始金额，不进行币种转换。

## 费用与数据

- 类型仅支持“港股”“美股”“A股”“债券基金”“股票基金”，默认选择“美股”。

- 股票单价必填且大于 0；基金单价选填，填写时也需大于 0。基金单价留空时在 Excel 中保持空白，列表显示“—”，编辑时仍为空。

- 股票在填写份额后：费用 = 总价 − 单价 × 份额，保留两位小数。不改写用户指定的卖出计算规则，因此差额可为负数。
- 股票份额必填且大于 0，费用自动计算。基金份额选填、费用可手填，默认 0。
- 代码输入中的英文字母对所有类型自动大写；数字代码继续遵循市场限制。代码始终按文本保存，保留前导零。按“类型 + 代码”关联历史名称。
- 名称首次必填。日期默认为设备本地当天。原因支持多行。
- 每条交易有 UUID，重复上传不会新增重复行。支持新增、查看、编辑与二次确认删除，编辑保留原 UUID。

## Microsoft / OneDrive 配置

1. 在 Microsoft Entra 注册应用，账户类型选择支持个人 Microsoft 账户（也可同时支持组织账户）。
2. 添加 **单页应用 SPA** 平台，重定向 URI 为部署网址的 origin + pathname，不包括 `#`。本机开发可注册 `http://localhost:3333/`；必须与实际访问地址完全一致。
3. 配置 Microsoft Graph 委托权限 `Files.ReadWrite`，组织租户如有要求由管理员批准。此权限允许用户授权后的文件读写。
4. 将公开的应用客户端 ID 填入本目录 `config.ts`，也可在页面设置里输入。**不能在前端放客户端密钥**。
5. 默认路径 `文档/BalanceSheet/TradingJournal.xlsx`，可在配置或页面中修改。连接后显示本机快照，点击“立即同步”才读取云端；首次手动同步创建缺失目录和文件。
6. 网络需要 `login.microsoftonline.com`、`graph.microsoft.com` 及 OneDrive 实际下载目标域名（账户相关）。浏览器须允许 Microsoft 登录弹窗，线上须使用 HTTPS。

登录使用 MSAL Browser 的授权码 + PKCE，Graph 通过官方 JavaScript SDK 访问。令牌由 MSAL 管理并缓存在 localStorage，不写入 Excel、配置文件或交易缓存。登录会话可用时刷新、关闭标签页后重新打开均可恢复；新设备需登录同一账户并配置同一路径。恢复登录不读取云端 Excel。

本机独立日记与每个账户/文件的云端缓存分别存储。切换账户或路径不会自动上传另一份日记。记录的本机待上传副本会在网络错误时保留，页面明确提示失败，可用“立即同步”重试。本机存储不是备份，建议定期导出 Excel。

同步先读取最新文件与 eTag，再按 UUID 合并并应用编辑/删除操作，使用 If-Match 更新；409/412 时重新读取合并，最多三次。新文件使用 conflictBehavior=fail，防止竞争创建时覆盖其他设备文件。无法识别的工作表、表头、非法行或重复 ID 均拒绝覆盖。一次读取最多 10MB。

## Excel 模板

仓库内模板：[resources/交易日记-模板.xlsx](../../../resources/交易日记-模板.xlsx)。设置面板也提供“下载空白 Excel 模板”。工作表名为 **交易记录**，列顺序为：

记录ID、日期、类型、代码、名称、看、方向、金额、单价、份额、交易费用、交易原因、头脑风暴。

应用用的记录ID不可删除或复用；在 Excel 手工增加行时须填写唯一 ID。金额列对应页面的交易总价，数值列应是普通数值，代码列保留文本格式。日期为 YYYY-MM-DD 或 Excel 日期；新记录类型为“港股/美股/A股/债券基金/股票基金”，看只接受“看多/看空/平仓”，方向只接受“买入/卖出”。请为此功能使用专用 .xlsx 文件，避免 ExcelJS 不支持的复杂工作簿功能丢失；不要把宏工作簿重命名为 .xlsx。

## 验证

`node --test tests/trading-journal.test.cjs`：费用、Excel 往返与前导零/长文本、格式拒绝、合并去重、路径校验、版本冲突重试和上传错误传播。

`npm run build`：生产构建。真实 Microsoft 登录和 OneDrive 读写需要有效客户端 ID 及授权账户；没有这些配置时不能声称已经完成真实云端验证。

## 编辑与删除同步

编辑/删除操作保存原始记录快照和唯一操作 ID。再次编辑同一条记录会合并本机待同步操作，保留最初的冲突基线。上传前比较云端记录：未变更时应用操作，已经变成目标状态时视为幂等重试，其他情况拒绝覆盖并提示冲突。另一个设备删除的记录不会被待同步编辑静默恢复。失败时保留操作，可导出当前本机可见记录备份；自动冲突合并不支持同一条记录双方同时修改。

Excel 写回会原位更新记录行，删除已移除的记录行，保留中文表头和其他工作表；模板表头无需升级。删除前有二次确认，界面不提供撤销。离线或网络失败时，删除操作先保留在本机同步队列，联网同步后才移除云端行。

## 手动同步

新增、编辑和删除只保存到当前账户/路径的本机队列；只有点击“立即同步”才合并并读写云端 Excel。连接、应用路径、页面进入、定时器、返回前台和恢复网络均不触发文件读写。登录恢复只恢复共享会话与本机快照。同步请求串行执行，保留原有 If-Match 冲突保护与操作 ID 去重；同步失败保留队列，可再次点击“立即同步”重试。

## 同步版本检查

每次同步先读取 OneDrive 文件 ID、eTag 和大小。没有待上传变更且 ID/eTag 与本次连接已验证的缓存一致时，只做一次元数据请求，不下载或解析 Excel。首次手动同步或手动同步发现云端版本变化/文件被替换时重新下载；文件删除时清空缓存。存在本机新增、编辑或删除时仍读取最新完整文件后合并，并保留 If-Match 冲突保护。上传成功后使用响应中的文件版本更新缓存；响应缺少版本或上传失败时，下次重新读取验证。缓存只保留在当前连接的内存中，不跨账户共享。

## 当前持仓

左侧菜单入口为“复盘工具 → 交易日记”，页面地址仍为 `/#/trading-journal`。

交易记录下方显示当前持仓，按“类型 + 代码”汇总全部可见交易，不受交易列表搜索和筛选影响。持仓区提供独立的类型筛选与代码/名称搜索，筛选只影响已汇总持仓的展示，不改变成本与份额计算；标题和底部计数显示筛选后的持仓数量。买入增加总成本及份额，卖出扣减卖出交易总价及份额；不重复加减费用。摊薄均价 = 总成本 / 净份额，总成本可因卖出回款高于累计买入额而为负。已清仓标的不显示；缺少任一交易份额时仅显示总成本，份额和均价显示“—”并提示补齐。不会根据单价反推未填写的份额。

新增、编辑、删除以及云端同步后的数据都会重新计算，包括本机待同步记录。持仓仅为交易记录的派生视图，不新增 Excel 工作表、列或本机持仓存储。请录入完整买卖记录以得到准确持仓。

## 共享登录与目录切换

同一 client ID 的交易日记与月度复盘共用 `src/services/onedrive-session.ts` 的 MSAL 实例、选定账户和会话。任一页连接后，进入另一页会静默恢复；同一账户应用新路径不再弹出登录。令牌仍由 MSAL 管理，使用 localStorage 持久缓存，选定账户也跨标签页关闭保留，功能默认配置与目录设置继续独立。旧交易日记账户偏好仅用于首次迁移，共享选定账户优先。

连接后可编辑 Excel 文件路径并点击「应用文件路径」。操作与同步队列串行，显示新路径的本机快照，点击“立即同步”才读取新路径数据，待同步记录留在原账户/路径缓存，不会随目录切换上传。后台仅恢复登录与本机快照，不访问云端 Excel，不打开授权弹窗；只有显式连接、同步或切换账户可交互授权。「切换账户」强制选择新账户，「断开共享登录」使同一 client ID 两页的旧连接失效，原草稿保留。已断开的旧本机设置不会自动恢复登录。


## 页面切换与按需加载

同一页面会话内按 Microsoft 应用、账户和文件路径复用登录及文件服务。返回页面先显示对应账户的本机快照，不在后台核对云端版本，只有点击“立即同步”才读写云端文件；后台失败保留本机记录，不锁定录入，也不弹授权窗口。文件 ID 和 eTag 均一致时复用已解析记录；切换账户、断开登录、删除文件或上传结果缺少版本时清除缓存。所有共享文件操作串行执行，保持 If-Match 冲突重试和本机待同步修改。ExcelJS 仅在读取、导出或同步 Excel 时动态加载。

`npm run test:onedrive` 覆盖共享登录恢复、账户和路径隔离、晚到响应、文件版本缓存以及按需加载。

交易原因下方的“头脑风暴”默认不勾选；勾选后 Excel 该列记录“是”，未勾选留空。旧 12 列工作簿兼容读取，保存时补齐该列。头脑风暴非实际成交，保留在日记中并标记，不计入持仓与实际交易费用；编辑、离线及同步保留该标记。

代码与名称双向匹配：先查当前 Excel 中类型相同的精确记录（本机模式查本机记录），优先使用最新日期的匹配；无匹配则使用东方财富免费证券搜索 HTTPS/JSONP 接口。仅使用同市场精确匹配；名称有歧义不自动选择。失败或无结果时待补全项留空，支持手动输入。输入防抖 350ms、超时 6 秒、过期请求取消；已匹配的另一字段可直接修改，清空两项可重新查询。不兼容旧分类。

代码、交易总价、单价、份额和交易费用输入框在点击及获得焦点时全选内容。金额类使用文本输入与 decimal 键盘，保存时仍由数值校验确保有效数字及正数约束，自动计算的费用保持只读但可选中复制。

股票录入顺序为单价、份额、总价、交易费用。未手改总价时，总价随单价与份额更新（十进制计算）；手改后保留输入并按差额计算费用。编辑已有记录时保留原总价，基金沿用原输入顺序。新增和编辑保存时交易原因必填，拒绝纯空白；读取已有 Excel 不强制补填历史原因。交易记录标的列按日期、代码·名称、类型·头脑风暴三行显示，份额在费用上方。删除确认使用 ToolDialog 首帧 CSS 居中，取消按钮显示中文。

股票份额必填且大于 0（允许碎股/小数）；基金份额仍选填。股票代码输入：A 股仅 6 位数字，港股仅 5 位数字并保留前导零；美股自动大写，支持 1–5 位字母及 . 或 - 分隔的 1–3 位类别后缀，例如 BRK.B。输入时过滤非法字符并限制长度，表单与保存时校验完整格式；基金不套用股票代码限制，已有 Excel 的代码读取规则不变。两张记录卡片的标题区底部 padding 均为 0，桌面和手机一致。
参考：[北交所六位数字代码指引](https://www.bse.cn/jygl_list/200021626.html)、[港交所证券代码示例](https://www.hkexnews.hk/stocklist_active_main.htm)、[Nasdaq 证券符号说明](https://www.nasdaqtrader.com/Trader.aspx?id=SymbolDirDefs)。

A 股与港股代码在离开代码输入框或按 Enter 时自动补前导零，分别补至 6 位、5 位，例如 1 → 000001、700 → 00700；输入过程中不提前补齐，空值不补。Excel 匹配、东方财富查询、名称反查回填及保存都使用补齐后的代码。美股与基金不补零。

上传与月度复盘一致：将 Excel 字节包装为 XLSX MIME 类型的 Blob 传给 Graph SDK，确保网络请求体为原始 Excel 二进制，不被序列化为 JSON。
