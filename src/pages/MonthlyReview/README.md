# 月度复盘

页面 `/#/monthly-review`，位于「复盘工具」。账本只保存在当前浏览器 IndexedDB；仅点击「发布到 OneDrive」时上传。导入的私人账本不打包到站点或源码仓库。切换账本保留各自草稿，切换 Microsoft 账户或文件夹不会自动发布其他来源文件。

## 模板与计算

支持原有 `Assets / XIRR / Liabilities / Analyze / WTH / XIRR-WTH` 工作簿结构。首次使用请导入现有 Excel，或连接 OneDrive 打开文件。新月份从当前账本创建，承接历史余额、保留历史交易、清零当期净投入和工资。期末余额需要更新；期间现金流由交易保存时按「上次记账日期之后、本次记账日期之前或当日」汇总。

`formula.ts` 使用受限表达式解析器执行模板需要的函数，不使用 eval。算术和汇总使用 Decimal；幂函数与 XIRR 使用浮点求解。XIRR 先进行 Newton 迭代，再在 log(1+r) 空间区间求根；多解情况下不能保证选择与其他软件完全相同的根。保留模板原有算术平均和估算收益口径，页面明确区分组合收益。缺失日期和无解等异常保留为提示，不填零。未知函数、循环或无法解析的公式拒绝导入。

`workbook.ts` 直接修改 XLSX 内部 XML，保留样式、其他包部件、工作表及公式。共享公式展开为等价独立公式，以便增删行；生成的文件写入当前计算缓存，设置打开时重算，并更新已识别图表缓存。支持产品新增/编辑/删除及买入/卖出/分红，维护跨表引用、区块范围、汇总和到期区间。新增产品的所属分组按成员、币种、产品类型去重，不含具体产品名或账户；账户从现有列表选择，也可手动新增，保存后自动进入账户筛选与下拉列表。新增产品上期余额固定为 0。

原模板的已知跨账户合并持仓按原收益公式中的买入行范围识别，首次编辑交易或删除时拆分为独立产品区块。未知关联结构停止操作。全部卖出时余额归零，保留历史收益；部分卖出需要另行填写最新期末余额。分红价格须为当日除息净值。保存前校验日期顺序、超卖和数值；操作先在副本执行，失败不会覆盖原草稿。

## OneDrive

复用交易日记的 MSAL 登录和 Graph SDK，使用 Files.ReadWrite 委托权限及当前站点 origin + pathname 重定向 URI。支持个人版 OneDrive 文件 API，不依赖 Excel 工作簿接口或服务端计算。默认配置单独存放在本目录 `config.ts`，初始 client ID 与交易日记一致，文件夹为交易日记文件所在目录 `文档/BalanceSheet`。运行时不读取交易日记配置或其浏览器设置，后续可以独立调整。已保存的月度复盘设置优先，可在设置面板点击「恢复默认配置」后重新连接。配置文件夹中的 `.xlsx` 会分页列出。

从云端打开的文件记录账户/文件夹来源、文件 ID 和 eTag。发布前验证云端版本，并通过 If-Match 上传；冲突不会自动合并或覆盖，保留本地草稿供下载核对。新文件请求 conflictBehavior=fail 与 If-None-Match，防止覆盖同名文件。下载和发布使用同一个生成器。网络失败不显示成功，不删除本机草稿。

## 验证

`node tests/monthly-review.test.cjs`：公式解析、XIRR 正负收益、引用调整、产品和买卖分红往返、清仓、删除、超卖、月份快照、云端冲突及错误传播。

可通过环境变量 `MONTHLY_TEMPLATE` 指定本地原模板，额外核对所有公式缓存和跨账户拆分，测试不会上传文件。私人模板不入仓库。

真实 Microsoft 登录与 OneDrive 发布需要用户在浏览器授权；接口模拟测试不代表真实云端端到端验证。完整 Excel 保真验证仍应包含在 Microsoft Excel 中打开下载文件并核查公式重算。

## 共享登录与目录切换

与交易日记共用同一 client ID 的登录会话，进入页面时静默恢复已连接的账户。账户选定与登录令牌由公共会话管理，功能目录独立；连接后修改文件夹并点击「应用目录」即可，不重复选择账户。不同 client ID 的会话隔离。

切换目录只重新列出当前目录文件，不移动已有账本。原目录账本的来源 ID/eTag 与草稿保留；若要发布到新目录，先显式选择「另存为当前目录副本」，再发布，新文件不会覆盖同名文件。「切换账户」强制选择账户，「断开共享登录」同时让另一个功能的同 client ID 连接失效。

## 新增产品与初始交易

新增窗口默认通过交易明细录入本期净投入，可跨月记录多笔买入、卖出及现金分红，实时展示买入合计、卖出回款、分红与净投入。新增产品无上期余额，明细日期必须在上次记账日之后、截至本次记账日，保存时同步维护资产表和 XIRR 区块。金额按实际收付填写，份额和价格用于持仓校验及 TWR；分红份额为 0，并提供除息后净值。超卖、缺失日期、日期倒序或超出期间的记录会阻止保存，原账本保持不变。

也可以切换「直接填写净投入」，只记录净投入与记账日余额，不保存暂填的交易明细；缺少日期时不伪造收益率，后续可在买卖记录中补充。净投入汇总使用 Decimal，买入为正，卖出回款和现金分红扣减。新增窗口与已有产品买卖记录复用同一个表格编辑器。

## 同名账本与来源

缓存按来源与文件名合并：本地同名文件重新导入会覆盖原条目；OneDrive 按账户、文件夹与文件名识别，应用客户端 ID 变化不产生同一云端文件的额外副本。不同账户、目录及本地/云端分别保留。导入先完成工作簿校验，再在 IndexedDB 单个事务中更新内容和清理重复条目，保持当前选项 ID 与实际保存 ID 一致。

启动时会整理以前保存的重复项，保留最近保存版本。下拉框显示「文件名 · 本地」或「文件名 · OneDrive」；多个云端位置同名时增加账户/目录说明。发布本地账本到云端后，缓存按其实际云端位置合并。此整理仅影响浏览器草稿，不自动改写 OneDrive 文件。
